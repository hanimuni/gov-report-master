# 템플릿 ① 정책검토보고서

> 4덩어리 기본형: **Why1(필요성) → Why2(실태·원인) → How(정책대안) → What(추진계획)**. 상세 사고법은 `references/01`, 문체는 `02`.

> **산출 계약** — 프로파일 `profiles/01-policy-review.profile.json` · kordoc preset `개조식` --org --approval · 게이트 방향 `both`. 정본은 프로파일 JSON이다.

## 질문 세트 (한 번에 하나씩)
- Q1: 어떤 정책의 검토인가요? (예: ○○법 시행령 개정 / ○○제도 신규 도입 / ○○지원사업 확대)
- Q2: 왜 지금 검토해야 하나요?(중요성+**시급성**) (예: 국정과제 ○○호 후속 / 언론 의제화 / 사각지대 발생)
- Q3: 현황과 문제점은? 그리고 **그 문제가 왜 생겼나(원인)**? (예: 대상 ○○만명 중 수혜 ○○%, 사각지대 ○○만명 — 원인: ○○)
- **Q3-1: 그 원인을 뒷받침하는 구체 사실·경위를 2~3개만 알려주세요.** (예: ○○년 제도 도입 당시 △△를 전제로 설계 / 담당 인력은 ○명 그대로 / 유사 사안 소송 ○건)
  ↳ `-` 층(본문 설명)에 채울 재료다. 이걸 안 받으면 `○`만 나열된 원고가 나온다.
- Q4: 목표·방향은? (예: 수혜율 80% 달성 / 3년 내 ○○명 추가)
- **Q4-1: 그 대안을 어떤 절차·조건으로 실행하나요?** (주체·기한·전제·선행조치) (예: 시행령 개정 후 6개월 유예 / ○○부 협의 선행 / 기존 대상자는 경과규정)
  ↳ 해결방안 장의 `-`는 46%가 **「어떻게」**다. 방법이 없으면 과제가 선언에 그친다.
- Q5: 예산·조직·일정 제약? (예: 별도 예산 없이 / ○○억 이내 / 6개월 내)
- Q6: 관련 자료(통계·법령·해외사례) 있으면 붙여주세요. 없으면 '없어'!
- 공통: 분량 / 문체 / 기존 양식

## 본문 뼈대

⚠️ **3층까지 채운다.** `□ → ○`에서 멈추면 라벨 나열이 된다. 아래 `-` 예시가 그 자리다.
`-`의 기능·개수 규범은 `references/14-content-density.md`.

```
Ⅰ. 보고 개요            [Why1] 결론 한 줄 + 검토 필요성(중요성+시급성)
 □ 보고 목적
   ○ 결론·핵심 메시지 (두괄식, 추진 배경과 별개로)
 □ 검토 배경·근거
   ○ 계기·조건·경과
     - 왜 지금인가 (인과)
Ⅱ. 현황 및 문제점        [Why2] 현황 → 문제 → 원인분석(1차→2차→3차)
 □ 현황·실태 (숫자 중심, 표)
   ○ 목표와 현실의 차이 + 통계
     * 수치·출처
 □ 문제점  ← 최소 3개
   ○ 문제 ①
     - 왜 그런가 (인과)          ← 진단 장의 첫 `-` 는 거의 항상 인과
     - 어디까지 해당하나 (범위)
     * 근거 수치
 □ 원인 분석  ← 깨포2: 여기 반드시
 □ 국내외 유사 사례 (참고)
Ⅲ. 정책 수단·대안 분석    [How] 원인을 없애는 방안
 □ 정책 대안 비교 [표: 대안 | 장점 | 단점 | 추진가능성(高中低)]
 □ 권고안 및 사유
   ○ (라벨) 과제 ①              ← 계획 장은 괄호 라벨이 핵심 장치
     - 어떻게 한다 (방법)        ← 방안 장의 첫 `-` 는 거의 항상 방법
     - 어떤 조건·예외가 붙나
 □ 예상 효과·부작용
Ⅳ. 추진 계획            [What] 내부자원(돈·사람·체계·근거) + 외부관리(시기·여론)
 □ 추진 일정 [표]
 □ 예산·재정 소요 [표]
 □ 관리·평가
Ⅴ. 건의 및 제안         결정을 구하는 사항 명시
【별첨】 / 【검증 요약표】
```

**장 배치** — 각 장은 `◇`(방침 선언, 첫 `□`보다 앞) → 본문 → `☞`(결론) 로 감싼다.
Ⅱ장 끝의 `☞` 결론이 Ⅲ장 머리의 `☞` 원칙으로 그대로 이어져야 한다.

## 깨포 점검
- Why1에 **시급성**("왜 지금")이 있는가?
- Why2가 문제 나열에 그치지 않고 **원인**까지 갔는가?
- Ⅲ(How)과 Ⅳ(What)이 섞이지 않았는가? (개선방안 목차에 추진계획을 쓰지 않기)
- 제목의 핵심 목적어와 실태분석 대상이 일치하는가? (남의 다리 긁기 금지)
- **문제점과 해결방안이 1:1로 연결**되는가? (문제1→방안1, 문제2→방안2)
- 조치사항(Ⅳ)에 **예산·일정·추진주체·역할분담·규정** 5요소가 있는가?
- **`-` 층이 채워졌는가?** `-`:`○` ≥ 0.8, 해결방안 장은 1.0~1.55. `○`만 나열된 섹션은 미완성이다.
- **각 `○`에 "Why so?"를 두 번 물어 답이 지면에 있는가?** 없으면 그 `○`는 아직 다 쓰이지 않았다.
- 현황·문제점에 **①차이 ②통계 ③부정적 결과 ④원인** 네 요소가 다 있는가? (교안 규정)
- **완결성 테스트** — 정책을 모르는 결재자가 읽고 되물을 것이 남지 않는가?
