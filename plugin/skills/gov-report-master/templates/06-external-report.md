# 템플릿 ⑥ 보고자료 (→상급기관)

> 상급기관에 올리는 업무 보고. 여러 기관이 순차 보고할 때 **차별 키워드**로 우리 의도를 드러낸다. 외부 공통 3요소(기획·쓰기·편집) 준수.

> **산출 계약** — 프로파일 `profiles/06-external-report.profile.json` · kordoc preset `보고서` --no-cover --no-toc · 게이트 방향 `min`. 정본은 프로파일 JSON이다.

## 질문 세트
- Q1: 무엇을 보고하나요?(추진현황 / 추진계획) 대상 상급기관은?
- Q2: 우리만의 차별 포인트(키워드)는?(예: 협업 / 지역특화 / 현장중심)
- Q3: 주요 실적·계획 항목은?
- Q4: 강조하고 싶은 성과는?
- 공통: 분량 / 문체

## 본문 뼈대
```
Ⅰ. 추진 개요           결론 + 우리 기관 차별 키워드 제시
Ⅱ. 주요 추진 실적/계획   중간 목차에 [차별 키워드] 삽입
 □ [협업] ○○ …        핵심 키워드 색·고딕 강조, 문단 5줄 이내
 □ [현장] ○○ …
 □ [지역] ○○ …
Ⅲ. 향후 계획·건의
```

## 깨포 점검
- 우리만의 **차별 키워드**가 목차에 박혀 있는가?("특별한 거 없음"에 굴복하지 않기)
- 키워드가 시각적으로 돋보이는가?(색·고딕)
- 문단이 5줄 이내이고 나열이 스토리로 엮였는가?
