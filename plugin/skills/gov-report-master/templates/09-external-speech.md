# 템플릿 ⑨ 말씀자료 (→행사 참석자)

> 행사 공식 스피치용(축사·기념사·인사말). **자료 없이 듣는 청중** 상대이므로, 세부 나열 금지. 핵심: **3키워드를 뽑아 한 줄로 압축 → 한자성어·중의로 확산**. 구두 전달은 `references/04`.

> **산출 계약** — 프로파일 `profiles/09-external-speech.profile.json` · kordoc preset `보고서` --no-cover --no-toc --no-page-numbers · 게이트 방향 `max`. 정본은 프로파일 JSON이다.

## 질문 세트
- Q1: 어떤 행사의 누구 말씀인가요?(장관·기관장 등) 길이는?(예: 3분)
- Q2: 이 자리에서 반드시 전할 **핵심 메시지 1~3개**는?
- Q3: 대상 청중의 관심사·정서는?
- Q4: 강조할 성과·비전, 인용할 문구·사례가 있나요?
- 공통: 톤(격려/축하/당부)

## 본문 뼈대 (말씀 흐름)
```
□ 도입           인사 + 이 자리의 의미(과거→현재→미래)
□ 본문 (3키워드) 사고·업무 양상에서 뽑은 키워드를 한자성어·중의로 확산
 ○ 키워드1 : 예) 현장 = 우문현답
 ○ 키워드2 : 예) 기본 = 사칙연산
 ○ 키워드3 : 예) 완벽 = 安全
□ 마무리          당부 + 격려 (새로움으로 공감)
```
※ 편집 원칙: 호흡 단위로 끊어 배치, 왼쪽 정렬, 순서어 고딕, 키워드 색.

## 깨포 점검
- 세부사업을 장황하게 나열하지 않았는가?(자료 없이 들으면 이해 불가)
- 3키워드로 압축돼 청중이 흐름을 따라오는가?
- 익숙한 상투구('위하여')가 아니라 **새로움**으로 공감을 주는가?
- 소리 내어 읽었을 때 자연스러운가?(말하듯이)
