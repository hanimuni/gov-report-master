# 템플릿 ② 계획수립보고서

> 이미 결정된 사항의 집행 계획. 핵심: **맨 앞에 기본방향(Why: 핵심 메시지)을 세운다.** "행사에도 Why가 있어야 한다." 사고법 `references/01`.

> **산출 계약** — 프로파일 `profiles/02-plan-establishment.profile.json` · kordoc preset `개조식` --org --approval · 게이트 방향 `min`. 정본은 프로파일 JSON이다.

## 질문 세트
- Q1: 무엇을 추진·개최하나요? (예: ○○제도 도입 세부추진 / ○○ 기념행사 / ○○사업 실행)
- Q2: 이걸 왜 하나요? — **한 줄 핵심 메시지**는? (예: "Beyond Standard, Toward Quality")
- Q3: 개요는?(일시·장소·대상·규모·주관) — 각 항목마다 "왜 이렇게?"
- Q4: 추진 단계·일정·역할 분담은?
- Q5: 예산·자원·리스크는?
- 공통: 분량 / 문체 / 기존 양식

## 본문 뼈대
```
Ⅰ. 기본 방향             [Why] 핵심 메시지·추진 방향 (이게 없으면 하수)
 □ 추진 목적·핵심 메시지
 □ 기본 원칙(모든 세부가 메시지와 정합)
Ⅱ. 개요                 [How] 일시·장소·대상·내용 — 각 항목에 "왜?"
 □ 개요 [표]
 □ 주요 내용·구성
Ⅲ. 추진 계획            [What]
 □ 단계별 추진 일정 [표: 단계 | 기간 | 주관 | 산출물]
 □ 역할 분담·협조 사항
 □ 예산 [표] / 리스크 대응
Ⅳ. 행정 사항           협조 요청·후속 조치
【별첨】 / 【검증 요약표】
```

## 개요 구성 3분기 공식 (성격별)
- **새로 추진**: ❶배경·목적 ❷일정 ❸예산 ❹내용 ❺세부계획 ❻기대효과 ❼행정사항
- **연례적인 것**: ❶성과·개선점 ❷운영방향 ❸예산 ❹세부운영계획 ❺행정사항
- **계획된 것**: ❶목적 ❷일정 ❸예산 ❹내용 ❺세부운영계획 ❻행정사항
- 행사 개요 포함사항: 성격·목적 / 일시·장소·참석자 / 주재자 / 행사내용. 회의는 목적·배경 / 일시·장소·참석자 / 주재자 / 주요내용.

## 예산 산출내역표 (필수 서식)
소요예산은 총액만 쓰지 말고 **산출근거**를 표로:

| 항목 | 산출근거(단가 × 수량) | 금액 |
|---|---|---|
| 예: 강사료 | 300,000원 × 4명 | 1,200,000원 |
| 예: 인쇄비 | 5,000원 × 200부 | 1,000,000원 |
| **계** | | **{{합계}}원** |

## 깨포 점검
- 맨 앞에 **왜 하는가(핵심 메시지)** 가 한 줄로 정의됐는가?
- 모든 세부(장소·순서·구성)가 그 메시지와 정합하는가?
- 예산이 총액이 아니라 **산출내역(단가×수량)** 으로 제시됐는가?
- 처음부터 끝까지 일관되게 점검했는가?
