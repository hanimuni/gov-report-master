# [샘플] 2018년도 산불방지대책 추진결과

- **유형**: 결과보고서
- **출처 기관·연도**: 산림청 남부지방산림청(2018)
- **원본 파일**: 3.결과보고서(사례2)2018년 산불방지대책 추진결과_산림청(2018).pdf
- **분량 추정**: 약 8쪽 (본문 4쪽 + 참고 통계·사진)

## 목차 구조 (실제 골격)
```
1. 산불발생 현황
   ❍ (총괄) / (시기) / (원인) / (지역) / (규모·시간대별)
2. 주요성과  (현장 사진 다수: 기계화 진화작업, 야간산불 진화현장 등)
3. 미흡한 점
4. (금후대책) 산불조심기간 이후 산불 대응 추진사항
참고 1. 주요산불 피해 현황 (피해면적별·시간대별·요일별·주요산불 표)
참고 2. 산불통계 (원인별 발생 통계)
```
- 소항목번호 `1~4` → `❍` → 괄호 라벨 `(총괄)/(시기)/(원인)…`. 참고자료에 통계표·현장사진 대량 수록.

## 핵심 특징 (이 샘플에서 배울 점)
- **연간 대책 결과보고의 4단 구조**: "현황 → 주요성과 → 미흡한 점 → 금후대책"으로 성과와 한계를 균형 있게 보고하고 다음 대책까지 연결.
- **"미흡한 점"을 독립 항목으로 자기평가**: 성과만 나열하지 않고 부족했던 부분을 명시해 보고의 신뢰성·개선 의지 확보.
- **현황을 괄호 라벨로 다각 분석**: (총괄)·(시기)·(원인)·(지역)·(규모)별로 쪼개 산불 발생을 입체적으로 진단.
- **참고자료의 통계표·현장사진 총동원**: 피해면적별·시간대별·요일별 표와 진화 현장사진으로 결과를 시각·정량 양면으로 입증.

## 대표 발췌 (산불발생 현황 원문)
> 1. 산불발생 현황
>  ❍ (총괄) 총 7건 발생(54% 감소), 산림 피해면적 12.75ha(2.1배 증가)
>  ❍ (시기) 봄철(6건, 12.6ha)에 집중 발생, 이후에는 평년수준으로 감소
>  ❍ (원인) 입산자 실화(4건, 57%)가 대부분, 기타(3건, 43%)
>  ❍ (지역) 고온건조한 날씨와 산림면적이 많은 경북에 산불피해 집중
>  ❍ (규모·시간대별) 대부분 1ha 미만, 발생시간은 12~18시(100%)에 집중
