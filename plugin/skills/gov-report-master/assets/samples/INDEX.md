# 정부 보고서 실제 사례 샘플 인덱스

> 이 폴더는 실제 정부 보고서 사례 18건의 구조·발췌를 담은 참조 애셋이다. 유형별 뼈대·문체·분량 감을 잡을 때 참조한다.

- 3개 유형(기획·상황·결과) × 각 6건 = 총 18개 샘플 카드.
- 각 카드는 실제 PDF에서 추출한 **목차 구조(뼈대)**, **핵심 특징(배울 점)**, **원문 발췌(개요/결론부)**를 담는다.
- 표기 규칙: 발췌 인용문은 원문 그대로를 옮기되, 자동추출 과정에서 유실된 표·그래프는 설명으로 대체했다. 억지 재구성은 하지 않았다.

## 유형별 뼈대 요약 (빠른 참조)

- **기획보고서**: `배경/현황 → 문제점 → (해외사례) → 추진전략·목표 → 세부 추진과제 → 기대효과 → 추진일정 → 붙임`
- **상황보고서**: `(머리글: 보고 취지·지시사항) → 상황/사고 개요 → 그간 조치사항 → 향후 계획·협조요청 → 붙임(위치도·명단)`
- **결과보고서**: `(머리글·요약) → 추진배경/경위 → 추진사항 → 추진 결과(정량 성과) → 미흡한 점 → 금후대책 → 참고(통계표)`

## 공통 문체·서식 관찰

- **개조식·명사 종결**: 서술어를 압축("~필요", "~제고", "~조성").
- **항목부호 위계**: `Ⅰ·Ⅱ` (대) → `1·2` 또는 `⑴⑵`·`①②` (중) → `□`·`○`·`❍` → `-` → `*`(각주).
- **두괄식**: 핵심 수치·결론을 맨 앞(머리글/요약)에 배치.
- **정량화**: 규모·비율·기간을 숫자와 각주 출처로 못박음.
- **청와대 비서관실 계열**('06·'07 사례)은 「◇ 머리글 + <요약> 선행」 형식과 페이지 러닝헤더가 특징.
