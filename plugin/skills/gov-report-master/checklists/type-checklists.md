# 유형별 자가 체크리스트 (Phase 6 최종 점검)

> 최종본을 내기 전, 해당 유형 항목을 점검한다. 공통 항목은 모든 유형에 적용.

## 공통 (모든 유형)
- [ ] 첫 문장이 결론인가?(두괄식)
- [ ] 안 준 숫자·법령을 지어내지 않고 `{{교체}}`로 표기했는가?
- [ ] `[AI]` 태그가 문단/항목 끝 1회씩 정확히 붙었는가?
- [ ] 한 문장 2줄 이내, 항목부호·종결어미가 통일됐는가?
- [ ] 숫자·사실 뒤에 의미(So What)가 있는가?
- [ ] **`-` : `○` ≥ 0.8 인가?** (해결방안 장은 1.0~1.55 / 상황·개요정리·말씀 제외)
- [ ] **`-`를 거느린 `○`가 절반 이상인가?** `○`만 나열된 섹션은 미완성이다
- [ ] **설명이 `※`가 아니라 `-`에 있는가?** 「없으면 이해 못 하는」 문장은 각주가 아니다
- [ ] `○`가 **술어로 닫히는가?** 조사를 지운 명사 나열이 아닌가
- [ ] **완결성 테스트** — 정책을 모르는 사람이 읽고 되물을 것이 남지 않는가?
- [ ] 검증 요약표를 붙였는가?

## 정책검토
- [ ] Why1에 **시급성**("왜 지금")이 있는가?
- [ ] Why2가 문제 나열을 넘어 **원인분석**까지 갔는가?
- [ ] How(방안)와 What(추진계획)이 섞이지 않았는가?
- [ ] 제목의 핵심 목적어와 실태분석 대상이 일치하는가?
- [ ] 대안 비교표(장점/단점/추진가능성)가 있는가?
- [ ] 문제점과 해결방안이 1:1로 연결되는가?

## 계획수립
- [ ] 맨 앞에 **핵심 메시지(Why)** 가 한 줄로 정의됐는가?
- [ ] 모든 세부(장소·순서·구성)가 메시지와 정합하는가?
- [ ] 단계별 일정·역할 분담이 표로 명확한가?
- [ ] 예산이 총액이 아니라 산출내역(단가×수량)으로 제시됐는가?

## 상황
- [ ] 과거→현재→미래가 MECE로 나뉘는가?
- [ ] 제목만으로 사건이 구체적으로 그려지는가?
- [ ] 사실과 추론을 구별했는가?(모르면 "확인 중")
- [ ] 불필요한 정밀 계산 대신 "약 ○○ 내외"로 신속성을 살렸는가?
- [ ] "정보 + α(전망)" 한 줄이 있는가?

## 개요정리(1쪽)
- [ ] 목차만으로 4덩어리가 한눈에 잡히는가?
- [ ] 1쪽을 1쪽으로 지켰는가?
- [ ] 만연체를 간결체로 끊었는가?
- [ ] 핵심만 본문, 나머지는 붙임으로 뺐는가?

## 회의참고
- [ ] 일반적 필요성을 매 쟁점 반복하지 않았는가?
- [ ] 쟁점별 주장→근거→사례가 두괄식(미괄식 금지)인가?
- [ ] 쟁점 개수만큼만 썼는가?
- [ ] 즉석 참고가 가능할 만큼 얇고 명료한가?

## 결과보고
- [ ] 목표 대비 성과(격차 축소)를 정량으로 보였는가?
- [ ] 계획 대비 실적 표(지표|목표|실적|달성률)가 있는가?
- [ ] 기대효과가 절감액·건수 등 정량으로 못박혔는가?
- [ ] 사진·통계치로 신뢰도를 확보했는가?

## 보고자료(외부)
- [ ] 우리만의 차별 키워드가 목차에 박혀 있는가?
- [ ] 키워드가 색·고딕으로 돋보이는가?
- [ ] 문단 5줄 이내로 스토리화됐는가?

## 협의자료(외부)
- [ ] 우리 역할과 상대 역할이 구분되는가?
- [ ] 상대가 각자 할 일을 이해하는가?
- [ ] 모든 문장 2줄 이내, 0.2줄 꼬리가 없는가?

## 설명자료(외부·보도)
- [ ] 핵심주제 중심으로 편집됐는가?(주제목·부제목·Lead·Body·Quote)
- [ ] 문장 2줄 이하 / 한 문단 3~4문장 / 한 문장 1주제인가?
- [ ] 형용사·부사·미사여구를 뺐는가?
- [ ] '밝혔다' 대신 스스로 화자로 썼고, 발언자 실명·연락처·보도희망일이 있는가?
- [ ] 시각자료(사진·도표)를 첨부했는가?

## 말씀자료(외부)
- [ ] 세부 나열 대신 3키워드로 압축됐는가?
- [ ] 익숙한 상투구가 아니라 새로움으로 공감을 주는가?
- [ ] 소리 내어 읽어 자연스러운가?

## 공문서 서식 검증 (제출용·HWPX 전, 2025 개정 기준)

- [ ] 시간: `09:00` 형식(쌍점 안 띄움)
- [ ] "끝." 표시가 규정 위치(본문끝/한계선끝/붙임끝)에 있는가?
- [ ] 붙임은 각각 나열(`1. …1부. / 2. …1부.`)했는가?
