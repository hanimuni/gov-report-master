# 공직윤리제도 발전방안

## Ⅰ. 검토 배경

□ 현행 제도가 상위계획과 어긋나 정합성 확보가 필요함
  ○ 이해충돌 심사 업무를 민간 전문기관에 맡김
  - 재산등록 심사 인력의 공백을 메움
  ○ 취업제한 규제를 조이고 심사 기준을 고침
  - 심사 인력을 늘리고 처리 기간을 줄임

## Ⅱ. 오탐 방지 확인 구간

□ 정합성 확보를 위해 제도를 정비하고 인력을 충원함
  ○ 최고치 경신, 구조여건 개선, 줄임말 정비, 핵심 키워드 도출은 정상 표현임
  ○ 소관 사무를 민간에 위탁하고 결원을 충원함
  ○ 사각지대 해소를 위해 붙임 자료를 함께 제출함
