# ① 기획 — 생각정리하기 (스토리를 찾아내는 사고법)

> 보고서를 쓰기 전 **가장 먼저** 하는 단계. 첫 문장이 안 나오는 이유는 글재주가 없어서가 아니라 **생각(스토리)이 정리되지 않아서**다. 이 파일의 도구로 스토리를 먼저 잡는다.

---

## 0. 대전제 — 정보 나열식 vs 스토리텔링식

하수는 아는 정보를 순서 없이 나열한다("정보 나열식"). 고수는 읽는 사람이 따라올 수 있는 **인과의 스토리**로 엮는다("스토리텔링식"). 같은 재료라도 결과가 갈린다.

| | 정보 나열식(하수) | 스토리텔링식(고수) |
|---|---|---|
| 구성 | 항목의 무순 나열 | Why→How→What 인과 흐름 |
| 결과 | "그래서 뭘 하라고?" | "아, 그래서 이걸 하자는 거군" |

---

## 1. 핵심 프레임워크 — 4개의 생각 덩어리 (⭐ 가장 중요)

흘러가는 생각을 **강제로 네 덩어리**로 나누면 보고서 전체의 스토리 골격이 잡힌다. 저자가 "이 책에서 가장 중요한 부분"으로 꼽은 틀. 특히 정책검토('○○개선방안', '○○활성화 방안')에 강력하다.

| 덩어리 | 명칭 | 핵심 질문 | 흔한 표현 |
|---|---|---|---|
| 첫째 | **Why1 (검토배경)** | 왜 중요? / 왜 지금? | 검토배경·추진배경·필요성 |
| 둘째 | **Why2 (실태분석)** | 현재 어때? / 무슨 문제? / **왜 생겼나?** | 현황·문제점·원인분석 |
| 셋째 | **How (해결방법)** | 어떻게 해결? | 개선방안·정책대안·해결방안 |
| 넷째 | **What (추진계획)** | 무엇을 하지? | 추진계획·집행계획·세부계획 |

### 덩어리별 상세

- **Why1(검토배경)** = 중요성 + **시급성**. "왜 지금 해야 하나, 나중에 하면 안 되나?"에 답한다. 어려우면 목차를 아예 '이 보고서를 읽어야 하는 이유: 중요성과 시급성'으로 먼저 써 보고, 나중에 '검토배경'으로 되돌린다.
- **Why2(실태분석)** = 현황(객관적 상태) + 문제점(현황과 목표의 차이) + **원인분석**. 현황·문제만 쓰면 안 되고, "그런데 그 문제가 **왜** 생기나"까지 파야 근본 대안이 나온다.
- **How(해결방법)** = **문제가 아니라 문제의 '원인'을 해결**한다. 예: 원인 1·2는 통제 가능 → "어떻게 고친다"(해결방안), 원인 3은 통제 불가한 외부 변수 → "어떻게 대응한다"(대응전략)로 나눠 쓴다.
- **What(추진계획)** = How를 실제로 굴리기 위한 실행. **내부 자원**(돈·사람·체계·근거)을 동원하는 계획 + **외부 요인**(시기·여론·갈등·성과)을 관리하는 계획.

### ⚠️ 3대 깨포 (보고가 '깨지는 포인트' — 고수가 한 번 더 챙긴다)

1. **깨포1 — 시급성 누락**: Why1에서 "왜 지금?"을 안 쓴다. → 반드시 시급성을 넣는다.
2. **깨포2 — 원인분석 누락**: 문제만 나열하고 원인을 안 판다. "논리가 뛴다"는 소리를 듣는다. → 원인까지 판다.
3. **깨포3 — How/What 혼동**: '개선방안' 목차에 추진계획을 쓰거나, 그 반대이거나, 마구 섞는다. → How(원인 제거)와 What(실행)을 분리한다.

### How와 What이 헷갈리는 3유형 (자가 점검)
| 유형 | 잘못된 모습 |
|---|---|
| 1 | '개선방안' 목차인데 추진계획만 씀 |
| 2 | '추진계획' 목차인데 개선방안만 씀 |
| 3 | 목차와 무관하게 내용을 마구 섞음 |

## 2. 유형별 덩어리 변형 (모든 보고서는 4덩어리의 응용)

종류가 달라도 결국 4덩어리를 변형·응용한다.

- **정책검토**: Why1 → Why2(원인) → How → What (기본형 그대로)
- **계획수립**: 맨 앞에 **기본방향(Why: 핵심메시지)** 을 세우고 → 개요(How)·추진계획(What). "행사에도 Why가 있어야 한다."
- **상황보고**: **시간 흐름이 곧 MECE** — 과거(사건개요·조치) → 현재(피해·영향·유관기관) → 미래(전망·대응). Why1·Why2·How+What을 시간축에 얹는다.
- **개요정리(1쪽)**: 4덩어리를 1쪽에 압축(I.개요=Why1 / II.추진상황=Why2 / III.개선방향=How / IV.추진계획=What).
- **회의참고**: 쟁점별로 수용/불수용 → 주장 → 근거 → 사례(두괄식).
- **결과보고**: 목표-현실 격차(gap) → 격차를 줄인 결과 → 정량 기대효과.
- **말씀자료**: 사고 양상에서 **3키워드**를 뽑아 한 줄로 압축.

## 3. 생각을 정리하는 도구

### 도구 1. 먼저 '왜(Why)'라고 질문하라 — 골든 서클
자료 요청·지시를 받으면 곧장 What(무엇)부터 하지 말고 **Why(왜)** 부터 묻는다(애플 골든서클: Why→How→What). "이 자료를 왜 찾지? 무엇을 판단하려는 거지?"를 알아야 헛수고를 안 한다. → 스킬에서는 생각정리 진입 시 항상 Why1을 먼저 확정한다.

### 도구 2. 덩어리로 생각하라
위 4덩어리. 흩어진 정보를 네 상자에 강제로 분류하면 스토리가 보인다.

### 도구 3. 중복과 누락을 없애라 — MECE / SWOT
- **MECE** (Mutually Exclusive, Collectively Exhaustive): 항목들이 서로 겹치지 않고(중복 X) 빠짐없이(누락 X) 전체를 덮는가. 보고서 목차·대안 목록을 MECE로 점검.
- **SWOT**: 내부 강점(S)·약점(W) × 외부 기회(O)·위협(T)으로 현황·전략을 정리. 실태분석·전략수립에 유용.
- 단, MECE는 목적이 아니라 수단 — 완벽한 분류에 집착하지 말고 "빠진 덩어리·겹친 덩어리"를 잡는 데 쓴다.

### 도구 4. 비교해서 좌표를 찾아라 — 십자형 전법
숫자 하나만으로는 의미가 없다. **두 축으로 비교**해야 좌표(의미)가 산다.
- **시계열(종적) 비교**: 전년 대비·여러 해 추이("작년보다 8%p 하락").
- **횡단면(횡적) 비교**: 다른 지역·기관·국가와의 비교("OECD 평균보다 낮음").
- **십자형 전법**: 시계열 + 횡단면을 **동시에**("전년 대비 하락한 데다, 경쟁 3사는 오히려 성장 → 우리만 뒤처짐"). 복합비교로 갈수록 의미가 뾰족해진다.

### 도구 5. 대안을 저울질하라 — 평가 매트릭스
How(정책대안)가 여러 개면 감으로 고르지 말고 **평가표**로 좌표를 찍는다.
- **Criteria Rating Matrix**(가중치 평가표): 평가항목(효과·비용·실현가능성·시급성 등)에 가중치를 주고 대안별 점수를 매겨 합산. 어느 대안이 왜 나은지 근거가 남는다.

  | 평가항목(가중치) | 1안 | 2안 | 3안 |
  |---|---|---|---|
  | 정책효과(40%) | 상 | 중 | 상 |
  | 소요예산(30%) | 하 | 중 | 상 |
  | 실현가능성(20%) | 중 | 상 | 중 |
  | 시급성(10%) | 상 | 중 | 중 |
  | **종합** | **○** | △ | ○ |
- **2×2 매트릭스**: 두 축(예: 효과 高低 × 난이도 高低)으로 대안을 사분면에 배치 → "효과 高·난이도 低"부터 착수. 우선순위 판단에 직관적.

### 도구 6. 마무리하고 수정하라 — 3C, 짧을수록 4덩어리
- **짧은 보고서일수록 4덩어리를 다 넣어라.** 1쪽이라고 Why를 빼면 스토리가 죽는다.
- **시간이 흐르면 보고서도 고쳐라.** 상황이 바뀌면 옛 보고서를 복사(하수)하지 말고 새 맥락으로 문제를 다시 푼다(고수: 인간 복사기가 아니라 문제해결자).
- **3C 관점**: 하수는 과거를 그대로 베끼고(Copy), 고수는 맥락(Context)·고객(Customer)에 맞춰 다시 구성한다.

---

## 4. 실무 적용 순서 (생각정리 단계에서 이대로)

1. 인터뷰로 모은 재료를 **Why1 / Why2 / How / What** 네 상자에 분류한다.
2. 각 덩어리를 **한 줄 요지**로 적는다.
3. **3대 깨포** 점검: 시급성(Why1) / 원인분석(Why2) / How·What 분리.
4. 십자형 비교로 핵심 수치의 **의미(So What)** 를 붙일 수 있는지 확인.
5. 사용자에게 덩어리 스토리를 제시 → 승인받고 나서 뼈대로.

> **핵심 한 줄**: 첫 문장이 안 나오면 글이 아니라 'Why1'을 못 잡은 것이다. 4덩어리로 스토리부터 세워라.
