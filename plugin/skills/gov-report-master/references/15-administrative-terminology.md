# ⑮ 행정용어 정본 — 비유·구어·고유어 동사를 행정용어로

> **한 줄 규칙: 정부 보고서의 어휘는 「쉬운 말」이 아니라 「행정에서 실제로 쓰는 말」이다.**
>
> 근거: 「국어기본법」 제14조(공문서의 작성·평가) · 「행정업무의 운영 및 혁신에 관한 규정」
> 제7조(문서 작성의 일반원칙) — 공문서는 어문규범에 맞게 한글로 작성한다. 이 규정은
> **쉬운 말**을 요구하는 것이지 **일상어·비유어**를 허용하는 것이 아니다.
>
> ⚠️ **이 문서는 문체를 바꾸지 않는다.** 개조식·명사형 종결(CORE RULE 9)은 그대로 유지하고,
> **어휘만** 행정용어로 확정한다. 「맡김 → 위탁」이지 「맡김 → 맡긴다」가 아니다.

## 0. 이 문서가 생긴 이유 (실패 사례)

「공직윤리제도 발전방안」 작성 시 아래 표현이 다수 발견되어 전면 수정해야 했다.

| 발견된 표현 | 무엇이 문제인가 | 행정용어 |
|---|---|---|
| 상위계획과 **어긋나** | 구어체 연결형. 위반인지 불일치인지 강도가 불명확 | **부합하지 않음** / **배치됨** / **위배됨** |
| 규제를 **조이고** | 비유(물리적 조임). 수단·정도가 안 보임 | **강화하고** / **요건을 상향하고** |
| 민간에 **맡김** | '맡기다'는 행정 행위를 지칭하는 말이 아님. 법적 행위 유형이 특정되지 않음 | **위탁** / **위임** / **이관** |
| 공백을 **메움** | '메우다'는 물리적 충전(비유). 무엇을 어떻게 채우는지 불명 | **보완** / **충원** / **충당** / **해소** |

공통 손해는 **어감이 가벼워지는 것이 아니라 행위가 특정되지 않는 것**이다.
'맡김'은 위탁·위임·이관 중 어느 것인지 결재자가 되물어야 하고, 그 셋은
**근거 법령과 책임 소재가 서로 다르다**. 어휘 문제가 아니라 **판단 가능성 문제**다.

## 1. 판별 3문 — 고칠 표현인지 30초 안에 가른다

한 표현을 두고 순서대로 묻는다. 하나라도 「아니오」면 바꾼다.

```
Q1. 이 말이 법령·훈령·예규·기존 공문에 그대로 쓰이는가?      (근거 있음)
Q2. 이 말을 들은 담당자가 '무엇을 하라는 것인지' 하나로 특정하는가?  (행위 특정)
Q3. 원래 뜻이 아닌 다른 영역에서 끌어온 이미지가 아닌가?        (비유 아님)
```

- 「메움」 → Q1 ✗(법령 용어 아님) · Q2 ✗(보완/충원/충당) · Q3 ✗(구멍 메우기) → **3중 위반**
- 「사각지대」 → Q1 ✓(복지·안전 법령·기본계획에 정착) → **허용**
- 「위탁」 → Q1 ✓ · Q2 ✓(수탁자·근거·책임이 따라옴) · Q3 ✓ → **정답**

⚠️ **Q1이 가장 강한 기준이다.** 「이 말이 어렵나 쉽나」로 판단하지 않는다.
어려워도 법령 용어면 쓰고, 쉬워도 근거 없는 일상어면 안 쓴다.

## 2. 금지군 ① — 행정에서 쓰지 않는 고유어 동사 (가장 많이 나온다)

**명사형 종결(`~함/~임/~음`)은 그대로 유지한다.** CORE RULE 9는 손대지 않는다.
문제는 종결 방식이 아니라 **어간에 놓인 어휘**다 — 행정은 `맡기다·메우다·조이다·고치다`로
행위를 지칭하지 않고 `위탁·보완·강화·개정`으로 지칭한다.

```
바꾸는 것 : 어휘(어간)          맡기 → 위탁      메우 → 보완
두는 것   : 개조식 명사형 종결   … 위탁함 / … 위탁 / … 보완함 / … 보완
```

따라서 **활용형 전부가 대상**이다. 명사형만 고치고 연결형을 남기면 같은 문제가 남는다.

```
❌ 민간에 맡김 · 민간에 맡기고 · 민간에 맡겨   ✅ 민간에 위탁 · 민간에 위탁하고 · 민간에 위탁함
❌ 공백을 메움 · 공백을 메우고 · 공백을 메워   ✅ 공백을 보완 · 공백을 보완하고 · 공백을 보완함
```

**작성 규칙(이 순서로 만든다)**

```
① 하려는 행위를 한자어 행위명사로 먼저 정한다   (위탁·보완·개정·정비…)
② 그 명사에 개조식 종결을 그대로 붙인다          (「… 민간 위탁」 / 「… 민간에 위탁함」)
③ ①에서 한자어가 안 떠오르면 그 행위를 아직 특정하지 못한 것이다 — 내용을 다시 본다
```

③이 핵심이다. **'맡기다'가 나왔다는 것은 위탁인지 위임인지 아직 안 정했다는 신호**다.
어휘를 고치는 대신 **판단을 먼저 끝낸다.**

### 치환 사전 (고유어 동사 → 행정 행위명사)

활용형·명사형을 함께 적는다. 오른쪽 명사에 `~함/~임`을 붙이면 개조식 종결이 그대로 유지된다.

| ❌ 고유어 동사 (맡기다·맡김·맡기고…) | ✅ 행정용어 (문맥별) |
|---|---|
| **맡기다 · 맡김** | **위탁**(사무를 밖으로) · **위임**(권한을 아래로) · **이관**(소관을 옮김) · **대행** |
| **메우다 · 메움** | **보완**(미비점) · **충원**(결원) · **충당**(재원) · **해소**(격차·공백) |
| 늘리다 · 늘림 · 넓히다 | **확대** · **증원**(인력) · **증액**(예산) · **연장**(기간) |
| 줄이다 · 줄임 · 좁히다 | **축소** · **감축** · **절감**(비용) · **단축**(기간) |
| 없애다 · 없앰 | **폐지**(제도) · **삭제**(조문) · **해소**(장애·격차) · **철폐**(규제) |

| 바꾸다 · 바꿈 · 갈아엎다 | **변경** · **전환** · **개편**(체계) · **전면 개편** |
| 키우다 · 키움 | **육성** · **강화** · **제고**(역량) |
| 살피다 · 살핌 · 알아보다 | **검토** · **점검** · **확인** |
| 챙기다 · 챙김 | **관리** · **점검** · **이행 확인** |
| 세우다 · 세움 | **수립**(계획) · **설치**(기구) · **제정**(규정) |
| 막다 · 막음 | **방지** · **예방** · **차단** · **억제** |
| 풀다 · 풂 · 풀어주다 | **완화**(규제) · **해소**(갈등) · **해제**(조치) |
| 묶다 · 묶음 · 잇다 · 이음 | **통합** · **연계** · **연동** |

| 다듬다 · 다듬음 | **정비** · **보완** |

> ⚠️ **명사형 종결을 서술형으로 바꾸는 것이 처방이 아니다.** 「민간에 맡김」의 해법은
> 「민간에 맡긴다」가 아니라 **「민간에 위탁」**이다. 종결은 그대로, 어휘만 간다.

| 좀 · 꽤 | **다소** · **상당수** |

## 6. 「쉽게 써라」와의 충돌 판정 ★

`02-writing.md` §5(어렵게 쓰면 아무도 모른다)와 이 문서는 **충돌하지 않는다.**
방향이 다른 두 축이기 때문이다. 판정 정본은 아래와 같다.

```
02-writing.md §5 가 겨냥하는 것 : 근거 없는 難漢字語·일본어투  (계출·가내시·토괴·경감시키는)
                        처방   : 등재된 순화어 · 표준 행정용어로 교체
15(이 문서)가 겨냥하는 것       : 근거 없는 일상어·비유·고유어 동사   (메우다·조이다·어긋나다)
                        처방   : 표준 행정용어로 교체
```

**둘 다 도착지가 「표준 행정용어」로 같다.** §5는 위에서, 이 문서는 아래에서 같은 지점으로
모은다. 따라서 §5를 근거로 「쉬우니까 고유어로 풀자」고 판단하면 **오독**이다.

| 방향 | 판정 |
|---|---|
| 계출 → **신고** | ✅ 어려운 한자어 → 등재 순화어 |
| 신고 → 알려줌 | ❌ 표준 행정용어 → 임의 고유어 (**이 문서가 막는 것**) |
| 보완 → 메움 · 메우고 | ❌ 동일 (활용형도 같다) |
| 메움 → **보완** | ✅ |

- [ ] 행위를 지칭하는 말이 **한자어 행위명사**인가? (맡기다·메우다·고치다 계열이 활용형까지 남지 않았는가)
- [ ] 고치면서 **명사형 종결을 서술형으로 바꾸지는 않았는가?** (「위탁」·「위탁함」 ✓ / 「맡긴다」 ✗)
- [ ] 다른 영역에서 끌어온 **이미지**가 없는가? (조이다·발목·물꼬·밑그림·빈틈)
- [ ] `어긋나`를 **부합하지 않음/배치됨/위배됨** 중 하나로 갈라 썼는가?
- [ ] 정도부사가 **매우·상당히·현저히**인가? (굉장히·엄청·꽤 없음)
- [ ] 남긴 고유어가 §5의 **허용 사유(규정 표기·등재 순화어·정착 용어·고유명사·인용)** 중 하나에 해당하는가?
- [ ] 한자어가 안 떠오른 항목은 **행위를 특정하지 못한 것**은 아닌가? (위탁/위임/이관 미결정)
