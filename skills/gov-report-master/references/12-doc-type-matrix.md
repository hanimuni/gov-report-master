## 1. ⚠️ `○`의 길이는 문서군에 따라 다르다 — 가장 중요한 분기

두 계측이 정면으로 엇갈렸고, **둘 다 맞다.** 문서군이 다르기 때문이다.

| 문서군 | `○` 길이 | `-` 하위 | 맥락 전달 방식 |
|---|---|---|---|
| **기획·상황·결과보고서** | **29~67자**(중앙 40) | **필수** (30~62자, 중앙 40) | `○` 요지 + `-` 설명의 **2층 구조**. `-`:`○` ≥ 0.8 |
| **업무보고(대통령·장관)** | **50~90자, 2~3행** | 거의 없음 | `○` **자체가 완결 서술 1문장** |
| **국회 검토보고** | 문장 단위 | 없음 | `○` 한 문장, 마침표로 닫음 |

업무보고 실례(기재부):
```
ㅇ (리스크 관리) 장·차관급 시장상황점검회의를 매주 개최해 시장 동향을 긴밀히
   모니터링하고, 외환·부동산시장 등 잠재 리스크를 철저히 관리
```

기획보고서 실례(과기정통부 2021):
```
ㅇ (자율) 연구개발 全단계(기획·수행·평가)에서 연구자의 자율성 최대 보장
 - 연구주제·규모·개수, 사업비 사용 항목 간 조정 등 연구수행에 필요한 주요
   사항을 연구책임자가 자율적으로 결정
```

> **선택 기준**: 결재선이 짧고 항목이 많으면 **업무보고형**(`○` 완결 서술),
> 논증이 필요하고 근거를 붙여야 하면 **기획형**(`○` 요지 + `-` 부연).
> 두 방식을 한 문서에서 섞지 않는다.

## 2. 불릿 체계는 문서군마다 고정이고 절대 섞이지 않는다

| 문서군 | 위계 |
|---|---|
| 업무보고 (국조실·행안부·기재부) | `□ → ㅇ → - → ※/*` |
| 주요업무 추진계획 (중기부) | `◇ → ◦ → ▪ → *` |
| 국회 검토보고 | `○` **단일** |
| 기획·상황·결과 | `□ → ㅇ → - → · → */※` |

`□`는 **종결어미를 쓰지 않는다.** 명사구 표제이거나 `→`로 후속을 잇는다.
```
□ AI 민주정부 구현 토대 마련
□ '26년을 '한국경제 대도약 원년'으로 만들기 위한 … 경제성장전략 마련 → '26.1월 발표
```

밀도 실측(업무보고 4건): **`□` 1~3개/쪽 · `ㅇ` 2.6~5.5개/쪽 · 쪽당 총 8~12항목.**
`□` 하나가 `ㅇ` 2~3개를 거느린다.

## 3. 서술톤 — 종결어미는 사실상 존재하지 않는다

| 묶음 | 계측 | 서술식 |
|---|---|---|
| 기획 6건 | 730블록 중 명사형 **82%** | `~다` **1건(0.1%)** |
| 상황·결과 12건 | 690줄 | `~다` **1줄** — 그마저 붙임 대국민 리플릿 |
| 업무보고 4건 | 336~433줄 | `~다/~함/~음` **한 자릿수** |

**세 묶음 24건에서 서술체 본문은 사실상 0이다.** 전부 한자어 명사 종결이다.

실측 종결 사전(빈도순):
```
추진 · 지원 · 강화 · 확대 · 마련 · 개선 · 조성 · 제고 · 대응 · 창출
완화 · 구축 · 검토 · 필요 · 확보 · 개최 · 활용 · 구성 · 양성 · 가능
```

### `~함/~임/~음`이 허용되는 자리 — 넷뿐

1. **머리글의 보고 행위** — 「보고 드림」 「보고하고자 함」 「점검·조정함」
2. **조사·설문 결과 인용** — 「~순으로 응답함」 「~것으로 나타남」
3. **판단 각주** — 「적정 재고는 61만톤임」
4. **국회 검토보고의 단정 강도 조절** — 아래 §7

> ⚠️ 「서술식으로 풀어 써 달라」는 요구를 받으면 **종결어미를 바꾸지 말고**
> `-` 항목을 늘려 맥락을 담거나(기획형), `○`를 완결 서술로 늘려라(업무보고형).

## 4. 괄호 라벨은 범용어가 아니라 **과제 고유명**이다

업무보고 실측: 라벨 대부분이 **문서 전체에서 1회만 등장하는 색인어**다.
```
(범정부 AI 확산) (공공데이터 개방) (전략적 관세정책) (비과세·감면 정비)
(폐업정리) (취업지원) (방재성능 상향) (리스크 관리)
```

범용 라벨 `(현황) (문제점) (추진방향) (검토사항)`은 **문제 진단 블록에서만** 쓴다.

상황보고서는 두 방언으로 갈린다.
- **사건형**(구제역·정전·산불) — 괄호 라벨을 쓰지 않고 **`○ 항목명 : 값`** 콜론형
  `○ 발생장소 : 동삼동 산149-46번지 일원` / `○ 동원인원 : 총 225명(영도구100, 소방75…)`
- **진행현황형**(법령용어 정비·AI 방역) — 괄호 라벨
  `○ (부처 선정) 모든 부처를 1차·2차로 나누어 2년간('18~'19) 집중 정비`

`○ (조치사항)` `○ (경과)` 같은 라벨은 **12건 어디에도 없다.**
조치·경과는 `○` 라벨이 아니라 **`□` 장 제목으로 올라간다** — 「□ 조치사항」 「□ 조치계획」 「□ 그간의 경위」.

## 5. 유형별 표준 목차 (인재개발원 교안 + 실측)

### 교안이 제시하는 고정 스키마

| 장 | 기획 | 상황 | 결과 |
|---|---|---|---|
| 1 | 개요 | 개요 | 개요 |
| 2 | 추진배경 | 추진배경 | 추진배경 |
| 3 | 현황 및 문제점 | 주요상황 | 현황 및 문제점 |
| 4 | **해결방안** | 시사점 | **추진결과** |
| 5 | 기대효과 | 후속조치 | 기대효과 |
| 6 | 조치사항 | — | 조치사항 |

> 교안 자신의 단서 — 「본 보고서 유형별 형식은 표준가이드 제공을 목적으로 제시하고 있으며,
> 실제 보고서 작성과는 상이할 수 있습니다」

**기획 ↔ 결과는 세 곳만 다르다 — 시제 스위치로 구현한다.**
```
기획 4장  해결방안  차이를 줄일 수 있는 방법(실현가능성·구체성이 관건)
결과 4장  추진결과  차이를 줄인 결과
기획 5장  기대효과  과제를 실행한 결과를 예측
결과 5장  기대효과  결과에 대한 시사점
```
1·2·3장 문구는 완전히 같다.

### 실측 골격 (기획 6건)

전건 공통은 **「세부 추진과제」 하나뿐**(6/6). 문제점 5/6 · 배경 5/6 · 목표·전략 5/6 · 추진일정 5/6.
**기대효과는 2/6로 필수가 아니다.**

→ 실무 골격 **`배경 → 현황·문제점 → 목표·기본방향 → 세부 추진과제 → 추진일정 → 붙임`**

### 3장과 4장은 「차이(gap)」의 진단·해소 쌍으로 강제 연결

> 교안 3장 — 「과제(목표)와 현실 사이의 **차이를 드러냄**(통계 활용) · 차이로 발생한 부정적 요소 및 **차이의 원인**」
> 교안 주의사항 — 「구성은 미리 파악한 문제점과 해결방안을 연결해야 합니다 **(문제점1:해결방안1)**」

**문제점 개수 ≠ 해결방안 개수면 위반**이다. 기계로 검사 가능하다.

### 개요는 두괄식이며 추진배경과 겹치면 안 된다

> 「1.개요 · **추진 배경과 별개로** 보고서 결론·용건(핵심 메시지)을 **두괄식**으로 전달하기 위해 작성」 — 3종 교안 동일 문구

제목에는 **해결방안·기대효과를 담되 개요와 중복을 피한다**(교안 3종 동일).

## 6. 문제→대책 연결 — 문제를 잘게 쪼개지 않는다

| 방식 | 출처 |
|---|---|
| 원칙 3개를 박스로 선언 → 같은 3개가 과제 ①②③ | 교육부 |
| **한계 ①②③ 번호가 추진사항 ①②③과 그대로 대응** | 과기정통부 |
| 단계 흐름도(`⇒`)로 병목 제시 → 전략/과제 정렬표 | 해수부 |
| **목표 `○` 5개와 과제 `□` 5개가 동일 문자열** | 문체부 |
| 원인/증상 분리 → 3축 × 5~6수단 → `☞ 별첨N` | 비서관실 |
| **문제 1개 + 대책 4갈래** — 5칸 고정 템플릿 | **행안부 업무보고** |

행안부 업무보고 Ⅳ장 원문 골격:
```
현황 → 문제점 → 추진방향 → 검토사항 → (조치사항 ①~④ 박스) → □ 향후 계획
```

**기획보고서의 문제 덩어리는 3~5개, 6개 이상은 0건.**
**업무보고는 문제를 1개만 세우고 대책을 4갈래로 편다.**

연결에 매핑 설명을 쓰지 않는다 — **번호나 문자열을 같게 만드는 것**이 관행이다.

같은 층위 항목은 괄호 라벨로 분류축을 맞추고, **진단축과 처방축을 같은 순서로 정렬**한다.
```
상황 3장  -(에너지·원자재)  -(금융시장)  -(실물경제)
상황 4장  ㅇ(공급망)        ㅇ(실물경제)  ㅇ(금융시장)
```

| 어미 | 쓰는 자리 |
|---|---|
| `있음` | 사실 진술 |
| `것임` | 성격 규정 |

```
○ 따라서 제정안과 같이 인공지능데이터센터 분야에 대해서만 별도 법률을 통해
```

## 8. 감사원 보고서는 개조식이 아니다

3,272줄 중 `하였다` 171회로 **완전한 문단형 서술체**이며 한 문장이 100자를 넘는다.
제목 자체가 판정문이다 — `~ 부적정`, `~ 미흡`, `~ 저해`.
혐의없음 항목은 `~ 관련`으로 중립화한 뒤 본문에서 `보기 어렵다`로 닫는다.

→ **감사·조사 결과 보고는 개조식 규칙을 적용하지 않는다.** 별도 장르다.

## 9. 각주는 세 부호로 분업한다

| 부호 | 역할 |
|---|---|
| `*` | 수치 근거·정의·출처·산식 |
| `※` | 항목 전체에 붙는 덧붙임·예외·전제·추정치 |
| `✔` | 완료 실적 낱개 (업무보고) |

**각주 밀도가 본문 2위계와 맞먹는다 — 쪽당 `*` 3~4개.** 형식도 고정이다.
```
* 연간 창업기업(만개, 중기부) : ('21) 141.7 → ('22) 131.7 → ('23) 123.8 → ('24.상) 62.2
```

> `*`와 `※`의 **병용은 금지가 아니라 관행**이다. 역할만 갈라 쓴다.
> (이 저장소의 옛 Q17 「혼용 = ERROR」 규칙은 실측과 어긋나 폐기했다.)

**결과보고서는 성과를 반드시 숫자로, 악화 지표까지 같은 줄에 적는다.**
```
❍ (총괄) 총 7건 발생(54% 감소), 산림 피해면적 12.75ha(2.1배 증가)
```

추상어(`제고·강화·활성화·효율화`)가 허용되는 자리는 **목적문 하나**뿐이다 — 「투명성 제고를 위하여 실시한」.

### 경과 타임라인 시각 표기 3규칙

```
| '22.5.29. 14:53 | 산불신고접수 | 16:49 | 산림청헬기도착 |
| 15:07 | 소방현장도착(화점확인) | 18:00 | 주불진화 |
| '22.5.30. 08:00 | 뒷불감시 |
```
① 첫 행만 `'YY.M.DD. HH:MM` 전체 ② 같은 날은 `HH:MM`만 ③ **날짜가 바뀌는 행에서만 날짜 재표기**
기간형은 총 소요를 괄호로 — 「2018.3.27. 12:00 ∼ 3.29.12:00 **(48시간)**」
일자만 쓸 때 `(M.D)` — 앞에 놓으면 진행, 뒤에 놓으면 결과, 미래는 「(9.19 예정)」

### 장 구성이 갈리는 세 지점

| | 상황 | 결과 |
|---|---|---|
| 1장 | **바깥 세계의 사실**(발생·발화 개요, 반드시 시각 동반) | **내부의 착수 근거**(추진배경·점검개요) |
| 중간장 | **행위주체별 분리**(농식품부 추진 / 축산원 방역) | 추진사항 → 정량 결과 |
| 끝장 | **남이 할 일까지 지시**(협조 요청 사항) | **자기평가 → 다음 주기**(미흡한 점 → 금후대책) |

**자기비판 장은 상황 0건 / 결과 2건.**

## 12. 서술 톤 — 단정의 강도 (정책연구보고서 계열)

우리 규칙은 문장 **구조**만 다루고 **단정의 강도**를 다루지 않았다.

| 조정 | 전 → 후 |
|---|---|
| 단정 완화 | 「왜곡이 발생함」 → 「고평가될 **소지가 있음**」 |
| 동사 겸손화 | 「설계함/구축함」 → 「**제안함/제시함**」 (단 제3자 행위는 원동사 유지) |
| 명칭·성격 명시 | 약칭 단독 사용 금지 |

도입 배경 — 「압축된 단정형 개조식이 딱딱·과장으로 읽히는 문제를 보완」

> 완화하되 **헤지어 범주**(근사·역접·강조·가능성)를 잃지 않아야 한다.
> 「약 30만 명」의 `약`, 「~로 보임」의 `보임`을 지우면 사실 왜곡이 된다.
