# ③ 편집 — 내 생각을 그려주는 생각 보여주기

> 편집은 마무리 꾸미기가 아니라 **내 생각을 읽는 사람 머릿속에 '그림처럼' 보여주는 세 번째 창작**. 마음가짐 ACE — Art(편집도 창작)·Concentration(집중)·Esteem(읽는 사람은 남이다). 손기술 = 다섯 편집법(빨리·일관·문맥·의미·확인).

본문을 표·도식으로 정리하거나 최종 서식을 다듬을 때 참조. HWPX 실제 서식·규정은 `06-hwpx-output.md`.

---

## 1. 빨리하자 — 마우스 대신 자판 (단축키·상용구)

편집의 본질은 '빨리하기'. 단순·반복 편집은 거의 다 자판으로.
- **단축키**: 예) 글자 크기 변경 = F3(영역 선택) → Alt+L(글자 모양) → 크기 입력 → 엔터. 손이 자판을 안 떠난다.
- **상용구**: 자주 쓰는 기호·단어를 짧은 준말로 등록(한글: 입력→상용구, Ctrl+F3). 예) `□`를 준말 'ㅂ'으로 등록 → 'ㅂ' + Alt+I → □. '근로기준법'을 '근'으로.
- **2:1의 법칙**: 마우스 하수 3시간 = 단축키 고수 1시간. **아낀 2시간을 '생각'(논리·문장 다듬기)에 재투자**하는 것이 빨리 편집해야 하는 진짜 이유.

> 스킬 관점: 이 스킬은 마크다운으로 산출하므로 단축키는 직접 쓰지 않지만, **최종 HWPX 편집을 사람이 할 때** 이 원칙과 아래 치트시트를 안내한다.

---

## 2. 일관성을 유지하자

글자 크기·모양, 자간, 줄 간격, 항목기호, 여백을 **처음부터 끝까지 통일**. 일관성은 가독성을 넘어 **의미의 정확성** 문제 — 깨지면 독자가 취지를 왜곡한다.
- 유지법: 시작할 때 Ctrl+A(전체 선택) → Alt+T(문단)·Alt+L(글자)로 일괄 통일.
- 왜곡 예: `□ → ○ → △` 순서로 쓰다 3쪽에서 ○를 건너뛰고 △를 쓰면, 독자는 "덜 중요해서 낮췄나?"로 오해.
- **절대 규칙은 없다.** 핵심은 "한 보고서 안에서" 정한 규칙을 끝까지 지키는 **내적 일관성**.

---

## 3. 문맥을 파악하자 — 글자 말고 흐름을 보여줘라

편집 목적은 한눈에 이해되게 하는 것. 문맥이 안 보이는 3대 원인·처방:
- **① 강조 부재** → 핵심어 강조(굵게/색).
- **② 빽빽함** → 글자·줄 간격 확보.
- **③ 단락 미구분** → 큰 항목(○)·하위 항목(- 들여쓰기)으로 위계 시각화.

⚠️ **순서 원칙**: 문맥 편집은 반드시 **문장 정리(②쓰기)가 선행**돼야 가능하다. 중구난방 문장엔 보여줄 문맥이 없다.
- **훑어 읽기(skim) 테스트**: 굵은 글씨·항목 머리만 따라 읽어 핵심이 잡히면 성공.

---

## 4. 의미를 보여주자 — 도식화

'보기 좋다' = 예쁘다가 아니라 **의미가 쉽게 이해되게 정리됐다**는 뜻. 글로 쓰기에 너무 길고 복잡하면(내가 그렇게 느끼면 독자는 이해 불가) **그림(도식)으로 그려라.**

### 생각 덩어리 종류 → 도식 선택
| 도식 | 언제(덩어리 성격) | 형태 예 |
|---|---|---|
| **흐름도** | 인과관계가 중요한 **관계형** | 순환형, 단순 흐름형 |
| **개념도** | 구성요소가 중요한 **나열형** | 목록형, 행렬형(매트릭스), 계층형 |
| **마인드맵** | 생각 확장이 중요한 **확장형** | 중심에서 뻗어나가는 형태 |

**도식화의 숨은 효과**: 그리는 과정에서 전체가 보여 덩어리의 **누락·중복을 스스로 점검**하게 된다(보여주기 도구이자 사고 검증 도구). ○·□·→ 손 스케치부터. 10쪽 넘는 보고서는 문장-도식을 번갈아 배치.

> 스킬 관점: 데이터는 표(지표|현재값|목표값|갭), 인과는 흐름도 텍스트(A → B → C), 대안 비교는 매트릭스 표로 산출한다.

---

## 5. 확인하자 — 무작정 끝내지 말고 한 번 더 읽어라

출력·결재 전 반드시 통독. **숫자로 읽지 말고 '의미'로 보라** — 의미를 생각하며 봐야 이상한 곳이 보인다. 윗사람이 던질 질문을 예상해 통계의 **단위·합계·추세 이상치**를 점검한다. 부분이 아니라 **전체의 시각**으로.

## 부록 A. 한글(HWP) 편집 단축키 치트시트

사람이 최종 HWPX를 편집할 때 안내한다(마우스 대신 자판). 니모닉이 있어 외우기 쉽다.

| 기능 | 단축키 | 비고 |
|---|---|---|
| 실행 취소 / 재실행 | `Ctrl+Z` / `Ctrl+Shift+Z` | |
| 특정 쪽 이동 | `Alt+G` | 쪽수 입력 |
| 글자모양 / 문단모양 | `Alt+L` / `Alt+T` | Letter / paragraph |
| 볼드 / 밑줄 / 이탤릭 | `Ctrl+B` / `Ctrl+U` / `Ctrl+I` | |
| 글자색 파랑/빨강/초록/검정 | `Ctrl+M` + `B`/`R`/`G`/`K` | 검정=K |
| 글자크기 확대 / 축소 | `Alt+Shift+E` / `Alt+Shift+R` | Enlarge/Reduce, 1pt씩 |
| 자간 좁힘 / 넓힘 | `Alt+Shift+N` / `Alt+Shift+W` | Narrow/Wide (가장 많이 연타) |
| 장평 좁힘 / 넓힘 | `Alt+Shift+J` / `Alt+Shift+K` | ㅓ/ㅏ 모양 |
| 줄 맞추기(정렬) | `Shift+Tab` | 표 안은 `Ctrl+Shift+Tab` |
| 줄바꿈(문장 유지) | `Shift+Enter` | 줄만 띄우고 문장은 하나로 → 줄맞춤 가능 |
| 쪽 나누기 | `Ctrl+Enter` | |
| 전체 선택 | `Ctrl+A` | 표 안에서는 표 내부로 한정 |
| 문자표 / 용지·여백 | `Ctrl+F10` / `F7` | |
| 겹낫표 「 」 | `Alt+F2` → 기타 → 겹낫표 | 법조문 인용 |
| 모양 복사 / 상용구 | `Alt+C` / `Alt+I` | |
| 표 만들기 / 행 추가 | `Ctrl+N,T` / `Ctrl+Enter` | |
| 표: 셀 블록 | `F5` | 이후 아래 키 조합 |
| 표: 속성 / 테두리·배경 | `P` / `L` | 셀 블록 상태 |
| 표: 셀 나누기 / 합치기 | `S` / `M` | |
| 표: 너비·높이 균일 | `W` / `H` | |
| 표: 커서 밖으로 | `Shift+Esc` | |

**실전 콤보**: `Alt+Shift+N` 연타(자간 축소) → `Shift+Tab`(줄맞춤). 자간으로 안 줄면 장평(`J/K`) 병행.

## 부록 B. 재사용 기호 팔레트 (항목부호·도형)

- **블릿·도형**: `□ ■ ○ ● ◇ ◆ △ ▲ ▽ ▼ ◁ ▶ ❏ ❍ ▪ ▫ ·`
- **화살표**: `→ ← ↑ ↓ ↔ ⇒ ⇐ ⇔ ⇨ ➡`
- **원문자·강조**: `① ② ③ ④ ⑤ / ❶ ❷ ❸ / ◈ ◎ ※ ☑`

## 부록 D. 빈 화면에서 시작하는 문서틀 셋팅 순서

새 보고서 착수 시: ① `F7` 용지·여백 설정(A4·좌우 20mm) → ② `Ctrl+A` 후 글자·문단모양 초기화(일관성) → ③ **줄간격 160%**(보고서) / 130%(기안문) → ④ 문단·조판부호 정리 → ⑤ 자주 쓰는 기호를 상용구 등록.

> 편집 수치의 정본은 `10-typography.md`다. 이전 판이 보고서에도 130%를 적었던 것은 기안문 값을 잘못 확대 적용한 것이다.
