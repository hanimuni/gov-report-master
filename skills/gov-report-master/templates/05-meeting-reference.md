# 템플릿 ⑤ 회의 참고자료

> 회의에서 참석자 발언을 돕는 글. **두괄식 + 쟁점 정리**. 즉석에서 참고 가능하도록 얇고 명료하게. 전달 화법은 `references/04`.

> **산출 계약** — 프로파일 `profiles/05-meeting-reference.profile.json` · kordoc preset `보고서` --no-cover --no-toc --no-page-numbers · 게이트 방향 `min`. 정본은 프로파일 JSON이다.

## 질문 세트
- Q1: 어떤 회의의 무슨 안건인가요?
- Q2: 쟁점은 무엇이고, 우리 입장은 수용인가 불수용인가?
- Q3: 각 쟁점의 근거는?(규정·논리 / 통계)
- Q4: 뒷받침 사례는?(우리 과거 / 타 기관)
- 공통: 분량(얇게) / 문체

## 본문 뼈대 (쟁점별 반복)
```
□ 안건 개요 (한 줄)
□ 쟁점 1 : ○○
 ○ 우리 입장 : 수용 / 불수용         ← 두괄식(결론 먼저)
 ○ 주장
 ○ 근거 : (논리적) 규정·이론 / (분석적) 통계
 ○ 사례 : (종적) 우리 과거 / (횡적) 타 기관
□ 쟁점 2 : … (동일 구조)
```

## 깨포 점검
- 일반적 필요성·시급성을 매 쟁점 반복하지 않았는가?(안건자료에 이미 있음)
- **미괄식(사례→근거→주장) 금지** — 주장을 먼저 냈는가?
- 쟁점 개수만큼만 썼는가?(분량 채우려 부풀리지 않기)
- 얇고 가벼워 회의 중 즉석 참고가 되는가?
