# 템플릿 ⑩ 결과보고서

> 시행한 정책·사업의 **추진결과(성과)** 를 보고. 기획보고서(사전 제안)와 **대칭**되는 사후 보고. 핵심 로직: **목표-현실 격차(gap)를 통계로 → 격차를 얼마나 줄였나 → 정량 기대효과**. 사고법 `references/01`, 서식 `06`.

> **산출 계약** — 프로파일 `profiles/10-result-report.profile.json` · kordoc preset `개조식` --org --approval · 게이트 방향 `min`. 정본은 프로파일 JSON이다.

## 질문 세트 (한 번에 하나씩)
- Q1: 무엇의 결과인가요? (예: ○○대책 추진결과 / ○○사업 완료 / ○○ 점검·조사 결과)
- Q2: 당초 목표·계획은 무엇이었나요? (예: 산불 30% 감축 / 시스템 6월 오픈)
- Q3: 실제 결과는? (숫자로 — 예: 산불 25% 감축, 예산 90% 집행)
- Q4: 목표 대비 격차(초과·미달)와 그 이유는?
- Q5: 앞으로의 조치·개선사항은?
- Q6: 사진·통계 자료가 있으면 붙여주세요.
- 공통: 분량 / 문체 / 기존 양식

## 본문 뼈대
```
Ⅰ. 개요                [결론 두괄식] 추진결과 + 핵심 성과 한 줄
Ⅱ. 추진 배경           (배경)추진 계기·경과 / (목적)취지
Ⅲ. 현황 및 문제점       목표(과제) vs 현실의 **격차(gap)를 통계로** + 원인
Ⅳ. 추진 결과           격차를 **얼마나 줄였나**(계획 대비 실적 표) — 정량
 □ 계획 대비 실적 [표: 지표 | 목표 | 실적 | 달성률]
 □ 주요 성과 (사진·통계치 첨부)
Ⅴ. 기대효과            정량 성과(절감액·건수)·시사점 — (단기)/(장기)
Ⅵ. 조치 사항           향후 추가 실행·개선·후속
【별첨】 / 【검증 요약표】
```

## 깨포 점검
- 한 일을 나열만 하지 않고 **목표 대비 성과(격차 축소)** 를 정량으로 보였는가?
- Ⅲ에서 격차를 **통계**로 드러냈고, Ⅳ에서 그 격차를 얼마나 줄였는지 **계획 대비 실적 표**가 있는가?
- 기대효과가 절감액·건수 등 **정량**으로 못박혔는가?(추상적 "제고" 금지)
- **사진·통계치**로 신뢰도를 확보했는가?
