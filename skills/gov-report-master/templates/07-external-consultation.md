# 템플릿 ⑦ 협의자료 (→타 기관)

> 기관 대 기관으로 우리 업무를 설명·설득. 핵심 스토리: **"내가(우리 기관) 하는 것 vs 남(타 기관)이 하는 것"** 을 명확히 구분. 문장 2줄 이내.

> **산출 계약** — 프로파일 `profiles/07-external-consultation.profile.json` · kordoc preset `보고서` --no-cover --no-toc · 게이트 방향 `max`. 정본은 프로파일 JSON이다.

## 질문 세트
- Q1: 어느 기관과 무엇을 협의하나요?
- Q2: 우리가 할 일 / 상대 기관이 할 일(협조 요청)은?
- Q3: 추진 상황·향후 계획 핵심은?
- Q4: 상대가 반드시 이해·결정해야 할 사항은?
- 공통: 분량 / 문체

## 본문 뼈대
```
□ 협의 개요           결론 + 협의 목적
□ 추진 상황           (우리 기관) ○○ / (타 기관) ○○ — 역할 구분
□ 협조 요청 사항       상대 기관이 할 일 [표: 항목 | 요청 내용 | 기한]
□ 향후 계획           우리 / 상대 각각
```

## 깨포 점검
- **우리 역할과 상대 역할**이 문장 단위로 구분되는가?
- 참석자가 각자 무엇을 할지 이해되는가?
- 모든 문장 2줄 이내, 0.2줄 꼬리가 없는가?
- "30분이면 쓰지"라는 대충하는 습관에 빠지지 않았는가?
